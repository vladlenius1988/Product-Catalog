# AI_NOTES

## Was AI used?

Yes. AI tools were used during development as a helper for brainstorming, UI improvements, debugging, and reviewing implementation ideas.

---

## Which parts AI helped with?

AI assistance was mainly used for:

- UI/UX improvement suggestions
- CSS layout and responsive fixes
- Compare/favorites state handling ideas
- React Context structure suggestions
- README structure review
- General debugging and code review discussions

---

## Which parts were manually reviewed or changed?

All generated suggestions were manually reviewed and adapted before being added to the project.

The final implementation, component structure, styling decisions, and state flow were manually adjusted during development.

Several UI and UX decisions were changed during implementation to better fit the project requirements.

---

## One example of an AI suggestion that was rejected or corrected

One AI suggestion used alert-based feedback for compare-limit handling.  
This approach was rejected and replaced with a disabled button state and inline UI hint because it provided a better user experience and matched the project UI more naturally.
