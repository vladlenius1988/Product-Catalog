# 🛒 Product Catalog

A React + TypeScript product catalog application with favorites, comparison, filtering, and sorting functionality.

---

## 🚀 How to install and run the project

### 1. Clone the repository

```bash
git clone https://github.com/vladlenius1988/Product-Catalog.git
cd Product-Catalog
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview production build

```bash
npm run preview
```

---

## ⚙️ Tech stack

- React
- TypeScript
- React Router
- Context API
- LocalStorage
- CSS Grid / Flexbox

---

## ✨ Implemented features

- 📦 Product listing grid
- ❤️ Favorites system with LocalStorage persistence
- ⚖️ Product comparison system
- 🔍 Category filtering
- 💰 Sorting by price, rating, and title
- 📱 Responsive layout
- 🔔 Visual indicators for favorites and compare pages
- 🧠 Shared state management with Context API
